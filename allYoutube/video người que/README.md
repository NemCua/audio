# Video nguoi que

Tool dung canh tinh cho video giai thich bang nguoi que.

JSON dau vao chi can la du lieu AI tach y, vi du:

```json
{
  "content": "Mot doan noi dung dai...",
  "scenes": [
    "Canh 1",
    "Canh 2",
    "Canh 3"
  ]
}
```

Layout cua tung canh duoc chinh trong tool: background chung, dang nguoi que, text, mui ten.

Nut "Duong canh" chi hien guideline trong editor de canh trung tam, khong phai du lieu canh de dua vao video xuat.
